# TaskStream

A lightweight task processing service built with Go, designed to handle concurrent tasks efficiently.

## Features

* **Concurrency**: Efficient task processing using goroutines
* **Graceful Shutdown**: Proper handling of SIGTERM signals
* **Health Monitoring**: Built-in health checks
* **Metrics**: Basic task processing metrics
* **Docker Support**: Easy deployment with Docker

## Getting Started

```bash
go run main.go
